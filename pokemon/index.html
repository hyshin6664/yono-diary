포켓몬 배경화면

포켓몬을 고르면 아이폰 배경화면을 만들어 줘요. 102마리 중에서 골라 보세요.

아이폰에 넣는 방법
  1. 포켓몬을 고르고 그림 종류와 배경 색, 잠금화면 / 홈화면을 정해요.
  2. 배경화면 만들기를 누르면 큰 그림이 나와요. 움직이는 그림을 골랐다면 그 순간의 모습이 담겨요.
  3. 그림을 꾹 누르고 「사진에 추가」를 눌러 저장해요.
  4. 아이폰 설정 → 배경화면 → 새로운 배경화면 추가 → 사진에서 방금 저장한 그림을 고르면 끝이에요.
✨ 움직이는 포켓몬
  • 위의 ✨ 움직이게를 누르면 목록의 포켓몬들이 전부 움직여요.
  • 포켓몬을 고른 뒤 그림 종류에서 ✨ 움직임을 고르면 미리보기 안에서 춤춰요.
  • 포켓몬마다 원래 움직임이 큰 것과 거의 없는 것이 있어요. 그래서 움직임 더하기를 처음부터 통통으로 켜 뒀어요. 제크로무처럼 조금만 움직이는 포켓몬도 확실히 움직여요.
  • 폴짝 · 빙글빙글 · 살랑살랑도 눌러 보세요. 움직임이 싫으면 없이를 고르면 돼요.
  • 움직이는 그림을 사진으로 가지고 싶으면 ✨ 움직이는 그림 저장을 누르고 꾹 눌러 저장해요. 사진 앱에서는 움직여요.
  • 다만 아이폰 배경화면에 넣으면 멈춰요. 아이폰은 배경화면에 쓴 그림을 한 장면으로 바꾸기 때문이에요. 그래서 배경은 멋진 한 장면으로 만드는 게 가장 깨끗해요.
  • 아이폰이 스스로 움직여 주는 배경은 설정 → 배경화면 → 날씨 / 천문학 두 가지예요. 포켓몬은 없어요.
🧊 3D 배경화면
  • 처음부터 ✨ 3D 입체로 켜져 있어요. 둥근 무대가 깔리고, 포켓몬 뒤에 빛이 번지고, 바닥에 비친 모습과 그림자까지 같이 움직여요.
  • 그림 종류에서 3D 그림을 고르면 게임 속 입체 모습이 나와요. 움직임 더하기 → 빙글빙글과 같이 쓰면 포켓몬이 좌우로 돌아가며 입체로 보여요.
  • ✨ 시계 앞으로를 고르면 포켓몬을 위쪽에 크게 그려요. 아이폰 잠금화면에 넣고 사용자화 → 사진에서 포켓몬을 조금 키우면, 포켓몬이 시계 앞으로 튀어나와 보여요(아이폰 깊이 효과).
  • 깊이 효과가 안 켜지면 포켓몬을 조금 더 키우거나 위로 올려 보세요. 시계를 너무 많이 가리면 아이폰이 효과를 꺼요.
